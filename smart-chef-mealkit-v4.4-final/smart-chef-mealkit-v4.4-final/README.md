# 스마트 셰프 AI — v4.4 최종판

## 새 기능
- 재료별 구입일자 입력
- 입력 항목: 재료명 / 용량 / g·kg / 구입일자
- 미래 날짜 입력 방지
- Gemini가 구입일자와 오늘 날짜를 비교해 구입 후 경과일을 고려
- 재료별 권장 사용기간을 '지금부터 얼마나 빨리 써야 하는지' 형태로 추정
- 오래된 재료를 밀키트에 우선 활용할지 AI가 판단
- 보관기한은 구입일자뿐 아니라 개봉 여부·포장 상태·냄새·색·점액 등 실제 상태 확인이 필요하다는 주의사항 포함
- 기존 밀키트 용량 검산, g/kg 변환, 가족 인원, 주간 식단 기능 유지

## 실행
기존 `.env` 파일을 새 폴더에 복사한 뒤:

npm.cmd install
npm.cmd run dev

브라우저:
http://localhost:3000

상태 확인:
http://localhost:3000/api/health

정상 버전:
mealkit-v4.4-final
